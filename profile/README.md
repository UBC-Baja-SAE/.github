# UBC Baja

UBC Baja is an automotive vehicle design team at the University of British Columbia.

We work to design a single-seat all-terrain vehicle to compete in the International SAE Baja competitions.
To learn more, check out our [Instagram](https://www.instagram.com/ubcbaja/), [LinkedIn](https://www.linkedin.com/company/ubc-baja-sae/about/), or [website](https://www.ubcbaja.com/)!
